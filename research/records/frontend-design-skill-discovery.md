# 前端设计 Skill 与 Prompt：收藏、效果预览和 Agent 驱动

> 原调研截至 2026-08-09；整理日期 2026-09-07。本文为历史调研整理，未在整理日重新联网核验；版本、许可、维护状态与测试数据均以原调研时点为限。

## 调研问题

是否有工具把设计 Skill/Prompt 收藏、真实生成效果预览和一键交给 Agent 串在一起？

## 结论

Design Skills Hub、TypeUI 与 21st.dev 接近不同环节，尚不能把目录或截图集合视为完整闭环。

- Design Skills Hub 以相同 brief 运行技能并展示截图/交互预览，接近“先看效果再选技能”；个人收藏能力需另核验。
- TypeUI 将设计系统、prompt、live preview 与 CLI/MCP 结合，但部分路径当时有付费边界。
- 21st.dev 在组件预览、收藏和代码安装上较完整，收藏对象主要是组件、主题和模板，不等于通用 Skill。
- 可信条目应同时记录技能版本、运行模型、输入 brief、截图或 live output、安装方式和证据来源。

## 证据与边界

原调研未登录付费产品，也没有对所有技能执行盲测。官方预览能证明展示内容，不证明第三方模型在任意任务中复现同样效果。

## 调研沿革

2026-08-09 完成该课题的资料核对与采用判断；2026-09-07 按课题归档，保留未决事项。

## 后续验证

- 建立固定 brief 和模型的评测样例，记录成功与失败输出。
- 验证个人收藏、导入、版本更新及从选品到 coding agent 执行的完整路径。
